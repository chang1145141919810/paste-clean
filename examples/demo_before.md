#三个方案对比

**核心结论：**先上线最小版本，再补数据和权限。

##方案一：直接复用现有模块##

现有模块已经覆盖了
大部分场景，所以不用重写。**注意**：接口的 `timeout` 要
单独设，不然会拖慢整体响应。

### 优点
- 改动小
- 上线快

### 缺点
- 扩展性一般
  - 后续加字段要改两处
    1. 数据库
    2) 接口层

| 维度 | 方案一 | 方案二 | 说明 |
|:---|:---:|---:|---|
| 开发量 | 3 人日 | 8 人日 | 只算主流程 |
| 风险 | 低 | 中 |

```python
def handle(req):
    # 保留缩进和空行

    if req.timeout > 3:
        return fallback(req)
```
